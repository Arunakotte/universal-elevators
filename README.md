# Universal Elevators — Website

Website for **Universal Elevators** — Premium Elevator Services in Bangalore (Installation, Repair & AMC).

## 🚀 Pages Included
- **Home (`/`)**: Main landing page with hero, service highlights, reviews, and contact info.
- **Services (`/services`)**: Residential, commercial, and industrial elevator solutions.
- **About (`/about`)**: Company overview, history, and engineering team.
- **FAQ (`/faq`)**: Frequently asked questions about lift maintenance & installation.
- **Contact (`/contact`)**: Contact details, office address, and quote inquiry.

## 🛠️ How to Run Locally

You can preview the website locally using any static server:

```bash
# Using Node.js / npx
npx serve . -l 3000
```
Then open `http://localhost:3000` in your web browser.

Alternatively, using Python:
```bash
python -m http.server 3000
```
